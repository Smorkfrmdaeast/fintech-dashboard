💳 SMORK'S PAYDOM
A modern, responsive, and interactive fintech dashboard built with HTML, Tailwind CSS, and vanilla JavaScript. Designed to simulate a real-world fintech experience with wallet management, transactions, bill payments, and smooth UX—fully branded as SMORK'S PAYDOM.
🛠 Features
Core Features
🔐 Login & Signup system with persistent localStorage.
💳 Wallet management with balance visibility toggle.
💾 Persistent transactions stored in localStorage.
📊 Transaction analytics chart for quick insights.
⚡ Smooth UX with animations, toast messages, and mini notifications.
🎯 Modal workflow for sending, receiving, funding, and paying bills.
🏦 Bank & provider selection for transfers and utility payments.
🟡 Floating social/contact button for Instagram, Facebook, LinkedIn, GitHub, and Email.
📺 Recharge & Bills: Pay electricity, DSTV, airtime, and more.
UX & UI
Modern glassmorphism design for dashboard and modals.
Responsive layout for mobile and desktop.
Clean, professional dark-theme color palette.
High-quality icons and animations for a real fintech app feel.

🚀 How to Run
Clone or download the repository.
Open login.html in your browser.
Create a new account or login with an existing account.
Explore SMORK'S PAYDOM dashboard:
View balance and transactions.
Send, receive, fund wallet, or pay bills via modal.
Select banks or service providers for payments.
Toggle visibility of wallet balance.
Check analytics chart.
Use the floating button to access social links or email.
No server required – runs completely in-browser using localStorage.
⚡ Technologies Used
HTML5 & CSS3
Tailwind CSS for utility-first styling
Font Awesome for icons
Vanilla JavaScript for functionality and state management
LocalStorage for persistence
