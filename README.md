# 💳 Fintech Dashboard Web App

A modern, responsive, and interactive **fintech dashboard** built with **HTML, Tailwind CSS, and vanilla JavaScript**. Designed to simulate a real-world fintech experience with wallet management, transactions, analytics, and smooth UX.

---

## 🛠 Features

### Core Features
- 🔐 **Login & Signup system** with persistent localStorage.
- 💳 **Wallet management** with balance visibility toggle.
- 💾 **Persistent transactions** stored in localStorage.
- 📊 **Transaction analytics chart** for quick insights.
- ⚡ **Smooth UX** with animations and toast notifications.
- 🎯 **Modal workflow** for sending, receiving, and funding money.
- 🟡 **Floating social/contact button** for Instagram, Facebook, LinkedIn, GitHub, and Email.

### UX & UI
- Modern **glassmorphism design** for dashboard and modals.
- Responsive layout for **mobile and desktop**.
- Clean, professional color palette and iconography.

## 🚀 How to Run

1. Clone or download the repository.
2. Open `login.html` in your browser.
3. Create a new account or login with an existing account.
4. Explore the dashboard:
   - View balance and transactions.
   - Send, receive, or fund money via modal.
   - Toggle visibility of wallet balance.
   - Access analytics chart.
   - Use the floating button to connect via social links or email.

> No server required – runs completely in-browser using `localStorage`.
